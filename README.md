# MediKiosk

A basic starter website for **MediKiosk** with a responsive navbar.

## Structure

- `index.html` – Main page markup with navbar, hero, and content sections.
- `styles.css` – Styling for the navbar and page layout, including a responsive mobile menu.
- `script.js` – Handles the mobile navbar toggle behavior.

## Running locally

Simply open `index.html` in your browser, or serve the folder with a local
static server, e.g.:

```bash
npx serve .
```
